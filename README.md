# Anime Hub Flask

A Flask-based anime web application built with authentication and database integration.

## Features
- User Registration & Login
- Secure password hashing
- Session-based authentication
- Blueprint-based project structure
- PostgreSQL database integration

## Tech Stack
- Python
- Flask
- PostgreSQL
- HTML

## Database Setup
- Set `DATABASE_URL` before running the app.
- Example: `postgresql://postgres:postgres@localhost:5432/self_flask`
